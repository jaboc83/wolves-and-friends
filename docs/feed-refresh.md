# Public feed collection

`lib/feeds/index.ts` registers provider tasks; `lib/feeds/provider-tasks.ts` runs at most six tasks concurrently with a 20-second refresh deadline. Every provider owns its buffer. Completed results merge in registration order, so response ordering does not depend on network completion. Failed or late results are excluded and reported in source health. Official fixtures retain their merge rules, live scoreboards overlay schedules, and injuries attach after those merges.

`lib/feeds/feed-parsers.ts` contains pure RSS/ESPN parsers, `lib/feeds/feed-types.ts` holds the normalized contracts, and `lib/feeds/news-sources.ts` configures publishers/authors. New providers should use the scoped transport so collection cancellation reaches upstream requests. Shared scoreboards use their independent short-lived cache; one collection timing out must not cancel another caller's shared fetch.

News, schedules and odds have separate per-Worker caches and in-flight requests. These are public data caches, not globally shared storage. The legacy combined endpoint only attempts odds within its remaining refresh budget, using isolated objects so late odds cannot mutate returned schedules. Author verification expires after an hour and holds at most 256 results.

Browser refreshes prioritize the selected page before loading other pages. Team views load their news and shared dashboard feeds first; All teams loads all news as visible content; March Madness loads its bracket first. Remaining news pages load sequentially, rechecking the selection before each request. Navigation starts the new page immediately without waiting behind an in-flight background request. Failed visible requests retain their existing fallback behavior and release the background queue. Selection stays in localStorage and is never included in a separate tracking request. Scheduling regressions are covered in `tests/page-first-feeds.test.ts`.

Preserve browser-only preferences, generic credentials-omitted/no-referrer feed calls, independent section completion, safe source-health codes and no stale seed headline injection. Regression coverage lives in `scripts/tests/feeds/test-provider-pipeline.mjs`, `scripts/tests/feeds/test-independent-refresh.mjs` and `scripts/tests/feeds/test-audit-feeds.mjs`.
